              Cómo crear el atajo (paso a paso)

              1 · Crear el atajo que habla

              1. Abre la app Atajos → pestaña Atajos → ＋.
              2. Ponle nombre, por ejemplo Allons-y mañana.
              3. Añade la acción Obtener contenido de URL y pega el enlace «Resumen de la mañana» de arriba.
              4. Añade la acción Leer texto (en algunas versiones, «Pronunciar texto»). Toca la flecha y elige idioma Español (España) y una voz de mujer.
              5. Pulsa ▶️ para probarlo: tiene que leerte tu agenda.

              2 · Que se ejecute solo

              1. En Atajos, pestaña Automatización → Nueva automatización.
              2. Elige Hora del día → 8:30 → Diariamente.
              3. Marca Ejecutar inmediatamente (y desactiva «Notificar al ejecutar» si no quieres el aviso).
              4. Elige el atajo Allons-y mañana.

              3 · Los demás

              1. Repaso durante el día: crea un atajo con el enlace «Repaso» y una automatización «Hora del día» para cada hora que quieras (por ejemplo 10:00, 12:00, 16:00, 18:00).
              2. Al ponerte los auriculares: atajo con el enlace «Al conectar los auriculares» y automatización Bluetooth → elige los StreetPods → «Se conecta» → Ejecutar inmediatamente.
              3. Resumen de la noche: atajo con el enlace «Resumen de la noche» y automatización a las 21:30.
              4. Apuntar con Siri: atajo llamado Apunta en Allons-y con: Dictar texto → Obtener contenido de URL (enlace «Apuntar», método POST, cuerpo JSON con un campo texto = Texto dictado) → Leer texto. Luego di «Oye Siri, apunta en Allons-y».

              Lo que apuntes con Siri aparece en Allons-y la próxima vez que la abras. Si cambias algo en la app, el atajo lo sabe en cuanto la app se guarda (necesita internet).

              📲 Allons-y para Android

              Con la app de Android te habla sola todo el día, aunque la cierres o bloquees el móvil, y te saluda al ponerte los auriculares.

              Descargar para Android

              Al abrir el archivo, el móvil te pedirá permiso para instalar apps de esta fuente: acéptalo. Antes, haz una copia de seguridad aquí abajo y recupérala en la app.

              Mensajes en pantalla

              Por si no llevas los auriculares: cada aviso sale también escrito en la app y como notificación del móvil.

              Voz

              Si no aparece ninguna voz de mujer de España, se puede instalar en el móvil. En Android: Ajustes → Accesibilidad (o Sistema → Idiomas) → Salida de texto a voz → motor de Google → Español (España) → elige una voz de mujer. En iPhone: Ajustes → Accesibilidad → Contenido leído → Voces → Español (España) → Mónica.
